# Pythonの並工処理について

## GIL
### プロセス内にあるスレッドは他のスレッドがインタプリタを実行している間は、処理ができない
- 1.Python内にあるC言語で書かれたプログラムがスレッドセーフが保証されていない
- 2. 各スレッドがインタプリタを実行する際、GILロックされることで、スレッドセーフになっている





### Pyhtonでパフォーマンスを向上させる方法
-  1. マルチプロセスによる並列処理
  * プロセスは相互不干渉->自身の為にGILをOSから割り当てられているので、他のプロセスの影響で処理が止まることはなく、並列処理ができる。

-  2. 非同期IOを使う
-  3. GILを無効にする (threading free CPython)

**GILとはの正体**
- インタプリタの機能の一つ、通信を管理する制御機構
**Python実行時に何が起きているか**
- インタプリタとプロセスの組が必要に応じて立ち上がる
- プロセスの中にはスレッドが存在している

**GILとプロセススレッドの関係性**
   * 単一プロセス
     - GIL(Process 1: Thread N)
   * マルチプロセス
     - GIL(Process 1: Thread N) X M 


***解決できない問題***
- 1.CPUバウンドな処理はマルチプロセスで並列化してもほとんど改善が見られない場合がある。
- 2. I/Oバウンドな処理はマルチプロセスで並列化すると、プロセス間の通信コストでかえって遅くなる場合がある。
